**Goal:** Add Azure-style Keys and Secrets sections while preserving the three existing sections.

**Tech Stack:** Existing Next.js, React, TypeScript, Tailwind, Heroicons, node:test and Testing Library.

## Global Constraints

- Work only in the recorded app worktree on codex/app-50-azure-style-vault-ui; API branch stays unchanged.
- Preserve Keys, Secrets and Advanced and their operations. Share namespace context and refresh state across all five sections.
- No service starts/restarts, live vault operations, merge, auto-merge or deploy.
- Single nonempty UTF-8 text file <=25 KiB, preserving BOM/newlines; explicit UTC dates; no clearing existing nbf/exp.
- Latest means newest created, with no fallback when inactive. RSA 2048/3072 and encrypt/decrypt only.
- Values/files/tokens remain in memory; metadata-only reads for editing; discard secret PUT response values.
- No automatic write retries; ambiguous results require checking history. No claim of runtime consumer refresh.

## Review Focus

- A late response after disconnect or navigation must not populate another context.
- Disabled latest remains current; older versions stay selectable as explicit choices.
- Invalid UTF-8, multibyte byte limits and BOM must preserve exact import semantics.
- A metadata-only writer must never need secret-value read permission.
- Timeout after a successful server write must not lead to an automatic duplicate version.
